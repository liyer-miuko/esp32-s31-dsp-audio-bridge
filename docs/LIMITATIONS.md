# 已知限制与验证范围

- 0.254 为实验参考身份，不是所有硬件/codec/切换组合的通过声明。此次整理没有构建、刷写或硬件测试。
- 之前 UAC 96 kHz/32-bit 约 120 秒计数观察无错误增量；计数不能证明逐样本保序或模拟音质。
- AAC 48 kHz 短窗观察到双源 BT 优先；最新完整停流回退和所有切码组合尚未重新验收。
- BLE 调音曾在 UAC 播放时完成配置与参数往返。它与串口共用控制互斥，可能有短暂音频干扰；未作产品级安全审计。
- LDAC 稳态曾出现 WDT、队列满和吞吐不足。即使 SDK 中有编译单元，也不代表默认允许协商或可实时播放。
- LHDC 已移除；LC3plus/aptX LL 没有适合来源时必须标记 NOT_TESTED。
- 双 I²S 共享 APLL，不保证帧相位对齐。I²S1 不支持右对齐格式。
- UI 的 130 biquad 是准入声明，不是任意参数/功能叠加下的通用实测保证。
- 压缩比字段可以存到 25.5:1，但冻结 DSP 处理上限为 20:1。
- I²C 功放框架与模板只有源码/协议层检查，没有实体 I²C/TAS 验收。
- 数字数据、计数或 UI 检查不等于功放模拟 THD、安全、失真或听感通过。
- 本仓库只发布源码和 WebUI，不分发 BIN/ELF；未包含所有依赖修改，不能独立重建 0.254。非商业用途或自行构建不自动解决第三方代码组合、专利、商标和分发义务。

WebUI 两种 JSON：完整配置文件覆盖 DSP、路由、端口和 GPIO 静音设置；DSP 参数文件只改音效，保留路由/端口等。功放 JSON 独立。导入不会自动保存 NVS。
