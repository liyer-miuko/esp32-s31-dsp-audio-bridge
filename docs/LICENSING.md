# 源码发布与许可问答

## 发布什么？

只发布应用源码、必要的 SDK/组件差异、单文件 WebUI 和文档。不提供预编译 BIN/ELF。固件需要使用者自行取得依赖和构建；被省略的文件明确列在 `sdk/manifest.json`，本包不能独立重建 0.254。

## DSP 和 UAC 能禁止商用吗？

对项目有权许可的原创部分，可以采用非商业许可。这里的原创 DSP/UAC 处理、WebUI 及其他原创贡献按 [PolyForm Noncommercial 1.0.0](../LICENSE) 提供，具体允许用途以标准许可为准。第三方已有代码、版权和许可不会因为位于 `dsp` 或 `uac` 文件中而变成本项目所有；原许可与要求沿用原许可的修改仍须保留。范围见 [LICENSE_SCOPE.md](../LICENSE_SCOPE.md)。

## 蓝牙按“原厂授权”分发就没有关系了吗？

不能这样理解。社区实现、SDK 集成和厂商正式授权不是同一回事。应按实际使用的实现及其许可判断，不能因为名称含 aptX、AAC 或 LDAC 就推定取得了厂商、专利或商业授权。

发布者需要履行自己分发内容的义务；接收者也要履行其使用、修改或再分发行为所适用的义务。版权、专利、商标和产品认证分别判断。本仓库没有提供专有 codec 商业授权或合规认证。

## 为什么不提供已有 BIN？

历史 0.254 的链接记录含 Helix AAC、freeaptx 和 LDAC。依据所见 [RPSL 4.1/4.2](https://opensource.org/license/RPSL-1.0)，Helix 对组合作品的许可有要求，不能仅靠按文件分许可认定完整镜像与非商业条款兼容。LDAC 解码实现的分发许可未确认；freeaptx 的实际源文件为 LGPL，静态镜像分发还有相应条件。具体证据见 [第三方通知](../THIRD_PARTY_NOTICES.md)。

这些是按现有材料作出的分发限制说明，不是对所有司法辖区作出的法律意见。没有假设存在项目未取得的单独商业授权。

## 让使用者自行构建，能保证没有法律风险吗？

不能保证。源码发布与二进制发布的内容范围不同，但发布的第三方源码本身仍有许可义务。自行构建、个人 DIY、非商业用途或免责声明，都不自动授予缺少的权利，也不能免除已经发生的分发义务。

使用者应在获取依赖、组合、构建、使用和再分发各阶段核对适用条款。遇到不明确的授权或组合问题，应在继续分发前向相关权利人确认，必要时请熟悉软件许可的法律专业人士审阅。
