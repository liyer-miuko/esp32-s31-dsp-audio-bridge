# 硬件与接线

目标为 ESP32-S31，双核 RISC-V，320 MHz；本设计不依赖 PSRAM。不能用于 ESP32-S3 或其他 ESP32 型号。

| 信号 | I²S0 | I²S1 |
| --- | --- | --- |
| MCLK | GPIO2 | GPIO13 |
| BCLK | GPIO3 | GPIO14 |
| WS / LRCK | GPIO4 | GPIO15 |
| DATA | GPIO7 | GPIO16 |

两路均由 S31 输出时钟，所用采样率跟随选中的音源，不使用 ASRC。共享 APLL 不代表帧相位锁定。请按 DAC 数据手册选择 I²S 格式；I²S1 不支持右对齐格式。

GPIO8 为可选 PCM 活动静音信号；默认低电平静音。逻辑按实际 UAC/BT PCM 活动的 OR 工作，全零 PCM 仍是活动。实际测试功放使用硬件模式，MUTE 接电源，并未连 MCU；不能假设软件静音已验证功放模拟静音。

可选 I²C 默认 SDA=GPIO9、SCL=GPIO10、100 kHz。总线与两个端口默认关闭。使用前自行确认引脚可用、电平、共地、外部上拉、器件地址和上电时序，禁止与既有 I²S 引脚冲突。

TAS5828M/TAS5825M 模板仅为基本初始化/静音示例，不是任意功放板的完整系数、保护、功率或扬声器适配方案。JSON 有严格大小/操作限制；I²C/NVS 与 DSP 配置分别保存。当前没有实体 I²C 功放验收。

先在低音量下核对路由与输出，再连接扬声器。错误格式、增益、系数或接线可能产生大幅噪声或损坏设备。不要将 GPIO 直接接到不兼容电压域。
