Frequency response This graph uses local settings. Drag an EQ point to change its frequency and gain.

Logarithmic frequency axis: 20 Hz to 20 kHz. Drag EQ points in magnitude view.
Gain axis: +/-15 dB. Each PEQ band accepts -12 to +12 dB.

Inputs USB and Bluetooth have separate gain, mute, phase, PEQ, and room EQ settings.

Route matrix Each cell selects a source channel and gain. Bluetooth has priority when both sources supply audio.

DSP DSP1/DSP2 feed I2S0. DSP3/DSP4 feed I2S1. Each channel has PEQ, high-pass, and low-pass filters.

Link channel pairs A change to one linked channel applies to both channels in that pair.

Channel DSP Set PEQ, high-pass, and low-pass filters for each channel. PEQ gain range: -12 to +12 dB. DSP1/DSP2: I2S0 left/right. DSP3/DSP4: I2S1 left/right.

Ports Port 0 uses DSP1/DSP2. Port 1 uses DSP3/DSP4. Set channel filters in the DSP panel.

Each DSP channel feeds one output slot. Select its input in the Routing panel.

Port 0 uses DSP1/DSP2. Port 1 uses DSP3/DSP4. Both ports have separate gain, delay, and channel settings.

Select the I2S format to match the receiving device. The selected source controls the sample rate.

Both ports share APLL. Frame phase alignment is not guaranteed.

I2S0: MCLK2/BCLK3/WS4/DATA7. I2S1: MCLK13/BCLK14/WS15/DATA16.

GPIO8 and optional I2C mute follow PCM activity. Digital-zero PCM is active. Connection alone is not activity.
