# 固件发布政策：仅源码，不发布二进制

本仓库只发布源码、配置、必要差异和 WebUI，不提供预编译 BIN/ELF。具备相应工具的使用者自行取得依赖并构建，参考[构建说明](../../docs/BUILD.md)。这项政策不表示任何人的第三方许可义务被转移或免除。

现有参考版本 **0.254** 的身份仅作来源记录，不是下载资产。历史镜像的分发限制包括：

1. 链接 map 确认包含 Helix `aacdec.c.obj`。其源文件保留 RealNetworks RPSL/RCSL 标识；RPSL 4.1/4.2 对组合程序许可有要求，不能在没有额外许可的前提下把现有组合程序整体变成非商业许可。未发现项目取得的 RCSL 授权。
2. map 同时包含 `ldaclib.c.obj`。尽管 LDAC 不默认参与协商，其代码仍进入镜像；本地库和所见上游未提供明确分发许可，不能用“默认关闭”忽略它。
3. `freeaptx.c` 的实际头部为 LGPL-2.1-or-later，与父目录 CC0 标签不一致。以后分发静态链接镜像前还需要准备符合该许可的对应源码、重链接材料及用户修改/调试权利安排。

自行修改依赖会形成不同的构建，需要另行记录身份并验证；不能当作未经更改的 0.254。自行构建、非商业用途或附加免责声明，都不能自动代替依赖所要求的授权及分发条件。详见[许可问答](../../docs/LICENSING.md)。
